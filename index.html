📖 Инструкция по запуску Whyexx 1.21.4

  1. Скачайте Bootstrapper.exe для автоматической установки или why-5.jar для ручной.
  2. При ручной установке поместите файл why-5.jar в вашу папку .minecraft/mods (требуется Fabric 1.21.4).
  3. Запустите игру и нажмите правую клавишу RSHIFT для открытия графического интерфейса (ClickGUI).
  4. Управление сервером, базой данных и правами пользователей осуществляется через скрипт console.py.
